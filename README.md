# シフトボード

お店の店長向けのシフト管理ページです。カレンダーでシフトを組み、スタッフの希望シフト提出、勤務時間と給料の目安の計算、Google カレンダーへの登録ができます。

## 本番ページ

https://claude.ai/artifact/RSUbvNbKGrUHdXPQVzTSP2

スマホのカメラで読み取ると本番ページが開きます。

<img src="qr.png" alt="本番ページの QR コード" width="240">

シフト・スタッフ・希望のデータは claude.ai 側に保存されます。実際に使うときは、claude.ai にサインインして本番ページを開いてください。スタッフは、共有メニューで一人ずつメールアドレスを入れて「編集者」として招待します（公開リンクはオフ。組織の外の人は、公開リンク経由だと閲覧のみになり、希望を提出できないため）。

管理者はページの作成者だけです。編集者として招待したスタッフにも管理者用の機能は表示されず、シフト・スタッフ・お店の設定は作成者しか書き込めません。時給とメールアドレスは作成者しか読めません。

GitHub Pages 版（https://ponntatta.github.io/shift-board/）では画面の見た目だけを確認でき、データの読み書きはできません。

## 機能

- **カレンダー**: 月表示と、週ごとのシフト表（スタッフ × 曜日）。日付を選ぶと、その日の勤務を時間帯のバーで表示
- **希望シフト**: 日付ごとに 〇 終日OK / △ 時間指定 / × 入れない を提出。全員の提出状況を一覧で確認
- **勤務時間・給料**: 実働・深夜（22〜5 時）・1 日 8 時間超を集計し、割増 25% 込みの給料の目安を表示
- **希望カレンダー（管理者だけ）**: 全員の 〇△× を日付ごとに 1 画面で表示。入れる人数と必要人数も表示
- **自動でシフトを組む（管理者だけ）**: 必要人数に足りない時間を、〇△ の希望がある人で、その月の勤務時間がなるべく等しくなるよう埋める案を作り、確認してから保存（1 人 1 日 9 時間まで、既存のシフトは残す）
- **必要人数と人手不足**: 管理者が曜日ごとに営業時間の時間帯と必要人数を設定すると、シフトが足りない日・時間・人数をカレンダー（月・週・その日の詳細）と PDF に赤く表示
- **PDF で保存**: その月の確定シフト表（誰が・何日の・何時から何時まで、出勤人数、一人ずつの実働合計）と希望シフト表を、A4 横の PDF にまとめて保存。カレンダー画面と希望シフト画面のボタンから使えます
- **Google カレンダー連携**: その日、またはその月のシフトを、開いている人の Google カレンダーに登録

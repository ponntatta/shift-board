# シフトボード

お店の店長向けのシフト管理ページです。カレンダーでシフトを組み、スタッフの希望シフト提出、勤務時間と給料の目安の計算、Google カレンダーへの登録ができます。

## 本番ページ

https://claude.ai/artifact/RSUbvNbKGrUHdXPQVzTSP2

シフト・スタッフ・希望のデータは claude.ai 側に保存されます。実際に使うときは、claude.ai にサインインして本番ページを開いてください。スタッフには、共有メニューで「参加者（Contributor）」権限を付けて招待します。

GitHub Pages 版（https://ponntatta.github.io/shift-board/）では画面の見た目だけを確認でき、データの読み書きはできません。

## 機能

- **カレンダー**: 月表示と、週ごとのシフト表（スタッフ × 曜日）。日付を選ぶと、その日の勤務を時間帯のバーで表示
- **希望シフト**: 日付ごとに 〇 終日OK / △ 時間指定 / × 入れない を提出。全員の提出状況を一覧で確認
- **勤務時間・給料**: 実働・深夜（22〜5 時）・1 日 8 時間超を集計し、割増 25% 込みの給料の目安を表示
- **Google カレンダー連携**: その日、またはその月のシフトを、開いている人の Google カレンダーに登録

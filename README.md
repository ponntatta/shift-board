# シフトボード

お店の店長向けのシフト管理ページです。カレンダーでシフトを組み、スタッフの希望シフト提出、勤務時間と給料の目安の計算、人手不足の確認、希望からの自動シフト作成ができます。

## ページ

https://ponntatta.github.io/shift-board/

スマホのカメラで読み取るとページが開きます。

<img src="qr.png" alt="ページの QR コード" width="240">

## 使い方

- **スタッフ**: 店長から届いた**招待リンク**を開くだけで参加できます。ログインは要りません。一度開けば、次からは同じ端末でページを開くだけで使えます。
- **店長（管理者）**: ページの「Google でログイン」から入ります。管理者は `firebase-config.js` と `firestore.rules` に登録した 1 人だけです。
- 招待リンクを持たない人は、ページの中身を見られません。
- リンクが漏れたときは、「スタッフ・設定」で「作り直す」を押すと、古いリンクと、古いリンクで参加した端末が使えなくなります。

## 機能

- **カレンダー**: 月表示と、週ごとのシフト表（スタッフ × 曜日）。日付を選ぶと、その日の勤務を時間帯のバーで表示
- **希望シフト**: 日付ごとに 〇 終日OK / △ 時間指定 / × 入れない を提出。スタッフは自分の分だけ出せる
- **希望カレンダー（管理者だけ）**: 全員の 〇△× を日付ごとに 1 画面で表示。入れる人数と必要人数も表示
- **自動でシフトを組む（管理者だけ）**: 必要人数に足りない時間を、〇△ の希望がある人で、その月の勤務時間がなるべく等しくなるよう埋める案を作り、確認してから保存（1 人 1 日 9 時間まで、既存のシフトは残す）
- **必要人数と人手不足**: 管理者が曜日ごとに営業時間の時間帯と必要人数を設定すると、シフトが足りない日・時間・人数をカレンダーと PDF に赤く表示
- **勤務時間・給料**: 実働・深夜（22〜5 時）・1 日 8 時間超を集計。時給と給料の目安は管理者だけに表示
- **PDF で保存**: 確定シフト表（誰が・何日の・何時から何時まで）と希望シフト表を A4 横の PDF に
- **カレンダーに入れる**: シフトごとの「Google カレンダーに追加」と、まとめて取り込めるカレンダー用ファイル（.ics）の保存

## しくみ

- データは Firebase（Cloud Firestore）に保存します。誰が何を読み書きできるかは `firestore.rules` で決めています。
- スタッフは Firebase の匿名ログインを使います（画面上の操作は要りません）。招待リンクの合言葉が正しいときだけ参加の記録（`sessions`）を作れます。
- 店長は Google ログインです。

## ファイル

- `index.html` … ページ本体
- `firebase-config.js` … Firebase の設定値と管理者の ID（公開されても問題ない値です）
- `firestore.rules` … データを守るルール（Firebase コンソールに貼り付けて公開する）
- `qr.png` … ページの QR コード
- `legacy/claude-artifact.html` … 以前の claude.ai 版（参考用）
- `.github/workflows/deploy.yml` … main に push すると GitHub Pages に自動公開
